# AstrBot 智能静默插件

让 LLM 根据上下文决定是否发言，避免机器人频繁回复、刷屏或过多地引用消息。

## 工作原理

插件通过三个事件钩子协同工作：

1. **`on_llm_request`**（请求前）：在群聊中向系统提示词注入一段隐蔽指令，要求 LLM 在认为无需发言时，回复内容仅以特殊前缀开头（默认 `@silent`）。
2. **`on_llm_response`**（响应后）：检测 LLM 回复是否以该特殊前缀开头，并标记事件。
3. **`on_decorating_result`**（发送前）：若检测到静默标记，则清空消息结果，彻底阻止消息发送。

## 规则

- **仅群聊生效**：私聊不拦截（可通过配置关闭限制）。
- **被 @ 强制回复**：当用户 @ 机器人或被唤醒指令触发时，静默逻辑不生效，机器人必须回复。
- **特殊前缀剥离**：若被 @ 时 LLM 仍带上前缀，插件会剥离前缀并正常发送正文。

## 配置项

| 配置项 | 说明 | 默认值 |
| ------ | ---- | ------ |
| `enable` | 是否启用静默 | `true` |
| `only_group` | 仅群聊生效 | `true` |
| `silence_prefix` | 静默特殊前缀 | `@silent` |
| `force_reply_on_wake` | 被 @ 或被唤醒时强制回复 | `true` |
| `inject_prompt` | 是否注入系统提示词指令 | `true` |
| `custom_instruction` | 自定义注入指令（留空用默认） | `""` |

## 注意事项

- **流式输出限制**：若开启 LLM 流式输出（streaming），消息会边生成边发送，发送前拦截可能失效。建议关闭流式输出以获取稳定的静默效果。
- 本插件需要与开启 LLM 对话的 AstrBot 一起使用（即机器人会主动回复群聊消息时）。
